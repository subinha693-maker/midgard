# 원고 형식 (`data/scenario/*.md`)

게임은 원고를 **실행 중에 직접 읽어서** 진행한다. 원고만 고쳐도 대사·연출·분기가 바뀐다.
문법 오류는 개발 모드(`?debug=1`)에서 왼쪽 위 **개발** 버튼에 파일 이름·줄 번호와 함께 뜬다.

## 기본

```
<!-- 초안 -->                 ← 주석. 여러 줄도 됨. // 로 시작하는 줄도 주석
# M01_아침                    ← 라벨. 이벤트·@goto·선택지가 이 이름으로 부른다
[아난:기본] 일어났어?          ← 대사. [인물:표정키] 뒤에 대사
[클로토:흠칫놀람] ……알면서.        ← 표정 CG는 항상 대사창 왼쪽 (배경은 실행 중에 지움)
[아난] 표정키를 빼면 기본 표정
[???] 표정 CG가 없는 이름은 이름만 나온다
그냥 쓴 줄은 이름 없는 서술(조사 문구 등)
줄 안에서 \n 을 쓰면 줄바꿈
```

- 라벨 하나는 **다음 라벨이 나올 때까지**가 한 덩어리다. 끝까지 실행하면 멈춘다(다음 라벨로 넘어가지 않음).
  이어서 가려면 `@goto`.
- 첫 라벨 앞의 글(제목, `초안` 표시 등)과 `## 머리글`은 무시한다.
- 표정키는 `data/portraits.json` 의 키. 없는 표정이면 그 인물의 기본 표정으로 나오고, 개발 모드 콘솔에 경고가 뜬다.

## 선택지

```
@choice
  - 아버지에 대해 묻는다 -> M01_아버지
  - 그냥 넘어간다 -> M01_계속
```
2~4개. 고르면 그 라벨로 넘어간다.

## 조건

```
@if 생일_아침_끝
...
@elif 횟수 >= 2
...
@else
...
@end
```

조건식 (맵 이벤트의 `if`·`show`에서도 같은 문법):

| 식 | 뜻 |
| --- | --- |
| `이름` / `!이름` | 플래그가 참 / 거짓 |
| `이름 >= 3` | 변수 비교 (`== != > < >= <=`) |
| `소지금 >= 100`, `일차 > 2`, `농도 >= 40` | 특수 값 |
| `아이템:생일 케이크` | 소지품이 있음 |
| `퀘스트:M01` / `완료:M01` | 퀘스트 받음 / 완료 |
| `시간:밤` | 지금 시간대 |
| `A && B`, `A \|\| B` | 그리고 / 또는 |

## 명령

| 명령 | 예 | 설명 |
| --- | --- | --- |
| `@goto 라벨` | `@goto M01_계속` | 그 라벨로 넘어감 |
| `@call 라벨` | `@call 공통_인사` | 그 라벨을 실행하고 돌아옴 |
| `@return` / `@stop` | | call 에서 돌아감 / 실행 멈춤 |
| `@flag 이름 = true` | `@flag 생일_아침_끝 = true` | 플래그 (`= false` 로 끄기) |
| `@var 이름 = 3` | `@var 횟수 += 1` | 변수 (`=`, `+=`, `-=`) |
| `@money +500` | `@money -30` | 소지금 (`=100` 으로 지정) |
| `@item 이름 +1` | `@item 생일 케이크 +1` | 소지품 (이름에 띄어쓰기 가능) |
| `@quest ID 시작 "목표"` | `@quest M01 목표 "마을을 둘러본다"` | 퀘스트 시작 / 목표 변경 / `완료` |
| `@time 아침` | `@time next` | 시간대 지정 또는 다음으로 (밤→아침이면 일차 +1). 바뀔 때마다 클로토 농도 -2, 7일마다 방세 훅 |
| `@concentration 대상 +10` | `@concentration 클로토 +15` | 발현 농도 (`=0` 으로 지정). 클로토가 100 에 닿으면 배드엔딩 |
| `@map 맵 x,y 방향` | `@map erisia_home 3,4 아래` | 맵 이동. 미리 `@fade out` 했으면 암전 유지 |
| `@move 대상 경로…` | `@move anan 왼쪽 왼쪽 위*2 대기:0.5 보기:아래` | 이동. 대상은 `플레이어` 또는 이벤트 id. 끝에 `대기없이` 를 붙이면 기다리지 않음 |
| `@face 대상 방향` | `@face anan 플레이어` | 방향 전환 (`플레이어` = 플레이어 쪽 보기) |
| `@show id` / `@hide id` | `@hide anan` / `@hide 플레이어` | 이벤트(또는 플레이어) 보이기 / 숨기기 (저장됨) |
| `@sprite 대상 시트` | `@sprite 플레이어 klotho_coat` | 걸음 도트 교체 (`data/sprites.json` 키) |
| `@speed 배율` | `@speed 0.6` | 플레이어 이동 속도 (M02 무기력 장면 등) |
| `@wait 초` | `@wait 0.5` | 대기 |
| `@timer 시작 초 실패라벨` / `@timer 끝` | `@timer 시작 20 M03_체력실패` | 제한 시간 (원고·메뉴 중에는 멈춤). 다 되면 실패 라벨 실행 |
| `@fade out 초 [흰색]` | `@fade in 1` | 페이드 / 암전 |
| `@shake 세기 초` | `@shake 0.01 0.5` | 화면 흔들림 |
| `@tint #색 세기 초` | `@tint #203060 0.5 1` / `@tint 끄기 1` | 색조 |
| `@distort 세기 초` | `@distort 0.12 1.5` | 화면 일그러짐 ('그녀' 연출) |
| `@cg 키 [초]` | `@cg 아난_전신` / `@cg 끄기` | 일러스트 (`data/illustrations.json`) |
| `@letter 키 [강조 "문구"]` | `@letter 생일메모 강조 "엽사가 되렴"` | 편지 창 (`data/letters/키.txt`) |
| `@subtitle "글" [초]` | `@subtitle "건년 666년, 노그리아 에리시아"` | 화면 가운데 자막 |
| `@battle 그룹 [패배라벨] [선제:아군\|선제:적]` | `@battle 원형1` | 전투 (`data/db/enemies.json` 의 groups). 끝나면 변수 `전투결과` = 1 승리 / 2 도망 / 0 패배. 그룹에 `retry` 면 지면 재시험, `scriptedLoss` 나 패배라벨이 있으면 지면 그 라벨로, 그 밖에는 병원에서 깨어나고 치료비(소지금 10%, 최소 100연) |
| `@save` / `@autosave` | | 저장 화면 열기 / 자동 저장 |
| `@bgm 이름` / `@se 이름` | | 받아만 두고 소리 없이 넘어감 (파일이 생기면 연결) |
| `@title` / `@end_demo "글"` | `@end_demo "M06으로 이어짐"` | 타이틀로 / 마지막 화면 |

방향은 `아래 위 왼쪽 오른쪽` 또는 `down up left right`.

## 장면 나누기 (프롤로그)

프롤로그는 변수 `진행` 하나로 장면을 나눈다. 맵 이벤트의 `show`·`pages` 조건이 이 값을 본다
(`tools/maps/build_maps.py` 의 `story()`).

| 진행 | 장면 |
| --- | --- |
| 0 | 콜드 오픈 |
| 10~15 | M01 생일 (아침 · 심부름 · 케이크 · 저녁 · 밤 · 다음 날) |
| 20~27 | M02 (일주일 · 시청 직원 · 2년 뒤 · 한스) |
| 30~34 | M03 (접수 · 체력 시험 · 실전 시험 · 혈액 검사 · 결과) |
| 40~44 | M04 (항구 · 갑판 낮 · 밤 · 새벽) |
| 50~60 | M05 (북항 · 추격 · 버스 · 시장 · 레브리 · 끝) |
